`e51a7ee2c231c6f1ed0adcd16c198e6a412a9c75`. Apache-2.0 LICENSE and upstream NOTICE retained.
Each .txt is a **modified excerpt**: one complete original bullet plus repository/release/source
headers. No original claim is rewritten. The manifest records its SHA256 and original URL.

20 diagnostic cases and 10 held-out cases were frozen before any provider execution.
The first 5 diagnostic cases are the initial probe. Held-out inputs use a separate user scope.
These are 30 excerpts from **one document/project**, not 30 independent conversations.
Queries and required literal substrings are agent-derived checks, not user-confirmed semantic golds.
Do not tune against held-out outputs or report substring recall as semantic accuracy.

This corpus covers real change reports, API names, versions, conditions and ambiguity. It does
not establish conversational correction/continuation quality, long-context coverage, official
Answer/Eval quality or production capacity. Existing synthetic correction/failure tests are
separate software contract checks and cannot close those real-material gaps.
